## 📌 Overview

**NexTalk** is a full-stack messaging application being developed with a focus on secure authentication, real-time communication, thoughtful user experience, and scalable backend architecture.

The goal is to build more than a basic chat interface. NexTalk is a hands-on engineering project exploring how modern messaging applications are designed, implemented, secured, tested, and eventually deployed.

The application is being developed incrementally, starting with the backend foundation and authentication system before moving into conversations, real-time messaging, and advanced infrastructure.

### 🎯 Project Vision

- 🔐 **Secure authentication** — Protect user accounts and sessions.
- 💬 **Real-time communication** — Build responsive, live messaging experiences.
- 👤 **User discovery** — Allow users to find and connect with other users through unique usernames.
- ⚡ **Responsive experience** — Create an intuitive interface across desktop and mobile devices.
- 🧱 **Maintainable architecture** — Keep the frontend, backend, validation, middleware, and business logic organized.
- 🚀 **Scalable foundations** — Explore technologies that support reliable communication as the application grows.

> **Current status:** NexTalk is actively under development. Features listed in the roadmap are planned work, not claims of completed functionality.

### Request Lifecycle

The intended request lifecycle follows a clear separation of responsibilities:

1. **Client:** Collects user input and sends an HTTP request.
2. **Routes:** Direct the request to the appropriate endpoint.
3. **Validation middleware:** Validates incoming data before business logic executes.
4. **Authentication middleware:** Checks credentials when an endpoint requires an authenticated user.
5. **Controllers and services:** Execute application logic and coordinate operations.
6. **Database:** Stores and retrieves persistent application data.
7. **Response:** Returns a consistent success or error response to the client.

This structure helps keep request handling, validation, security, and business logic maintainable as the project grows.

## 🔐 Authentication Design

Authentication is one of the first major components being implemented in NexTalk.

### Current Authentication Flow

**Registration**

1. The client submits registration details.
2. The backend validates the request.
3. The password is hashed using Argon2id.
4. The account is created and the API returns its response.

**Login**

1. The client submits login credentials.
2. The backend validates the request and checks the account.
3. The supplied password is verified against the stored hash.
4. A JWT-based authentication credential is issued in an HTTP-only cookie.
5. Protected endpoints use authentication middleware to validate the session.

**Logout**

The client requests logout, and the backend clears the authentication cookie.

### Planned Authentication Improvements

- Google OAuth and Sign in with Apple.
- Email ownership verification during registration.
- Secure, time-limited, single-use email OTPs.
- OTP attempt limits and resend cooldowns.
- Login and registration rate limiting.
- Consistent validation and error-handling middleware.
- Secure account linking for users with multiple sign-in methods.
- Improved session expiration and authentication lifecycle tests.

### Security Principles

- Never store plaintext passwords.
- Never expose secret keys or credentials in the frontend.
- Validate incoming data on the server.
- Use HTTPS in production.
- Apply appropriate cookie security settings.
- Limit repeated authentication and verification attempts.
- Verify third-party identity tokens on the backend.
- Avoid automatically linking accounts based only on an unverified email address.
- Keep secrets in environment variables and out of version control.

## 💬 Planned Real-Time Messaging

Real-time communication is a core part of NexTalk's long-term vision.

Socket.IO is planned for bidirectional communication between connected clients and the server.

The intended messaging lifecycle is:

1. A user authenticates and establishes a connection.
2. The server verifies the user's identity and conversation access.
3. The sender submits a message.
4. The server validates the message and persists it.
5. Authorized conversation participants receive the message in real time.
6. Message history can be retrieved when a user reconnects.

Additional features may include online presence, typing indicators, delivery/read receipts, message pagination, and reconnection handling.

Redis may be introduced for shared presence state, ephemeral data, or multi-instance Socket.IO coordination if the architecture requires it. It is not a replacement for persistent message storage.

## ⚙️ Getting Started

Follow these steps to set up the project locally.

### Prerequisites

Install the following:

- Node.js — a supported LTS version.
- npm.
- MongoDB — a local instance or a configured MongoDB deployment.
- Git.

### 1. Clone the Repository

```bash
git clone https://github.com/Dikshant6/NexTalk
cd NexTalk
```

Replace the placeholder with the actual repository URL.

### 2. Configure the Backend

```bash
cd server
npm install
```

Create a `.env` file using the existing `.env.example` as a reference.

Example configuration:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=your_mongodb_connection_string
CLIENT_URL=http://localhost:5173
JWT_SECRET=replace_with_a_secure_random_secret
```

These variable names are illustrative. **Use the exact names and requirements defined by the current backend configuration and validation schema.** If the application uses separate access-token secrets, email credentials, or OAuth variables, configure those as required by the implementation.

Never commit your real `.env` file.

Start the backend using the script defined in `server/package.json`. For example, if the project defines a development script:

```bash
npm run dev
```

### 3. Configure the Frontend

Open a second terminal:

```bash
cd client
npm install
```

Create a `.env` file in the client directory:

```env
VITE_API_URL=http://localhost:5000/api
```

The URL must match the actual backend port and API mount prefix.

Start the frontend:

```bash
npm run dev
```

Vite will print the local development URL in the terminal, typically `http://localhost:5173`.

### 4. Verify the Setup

- Open the frontend in your browser.
- Confirm the backend starts successfully.
- Check the configured health endpoint, if enabled.
- Test registration, login, protected session retrieval, and logout.
- Check browser and server logs if a request fails.

The exact scripts and environment variables should always match the current `package.json` files and backend configuration.

  return (
    <Routes>
      {/* Public application */}
      <Route element={<SiteLayout />}>

          <Route path="/register" element={<RegisterPage />} />

        </Route>
      </Route>
    </Routes>
  );
}

export default function App() {
  return (
    <BrowserRouter>
      <AuthProvider>
        <AppContent />
      </AuthProvider>
    </BrowserRouter>
  );
}

import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Link, useLocation, useNavigate } from "react-router-dom";
import { useState } from "react";
import { authService } from "@/services/auth.service";
import SocialAuthButtons from "@/components/auth/SocialAuthButtons";
import { useAuth } from "@/context/AuthContext";

export default function AuthForm({
  isRegister,
  email,
  setEmail,
  password,
  setPassword,
  onToggleMode,
  children,
}) {
  const { refreshUser } = useAuth();
  const navigate = useNavigate();
  const location = useLocation();

  const [internalEmail, setInternalEmail] = useState(
    location.state?.email || "",
  );
  const [internalPassword, setInternalPassword] = useState("");

  const currentEmail = email !== undefined ? email : internalEmail;

  const handleEmailChange = (val) => {
    if (setEmail) setEmail(val);
    else setInternalEmail(val);
  };

  const currentPassword = password !== undefined ? password : internalPassword;

  const handlePasswordChange = (val) => {
    if (setPassword) setPassword(val);
    else setInternalPassword(val);
  };

  const [loading, setLoading] = useState(false);
  const [error, setError] = useState("");
  const [success, setSuccess] = useState(
    location.state?.successMessage || location.state?.message || "",
  );

  const handleSubmit = async (event) => {
    event.preventDefault();

    setError("");
    setSuccess("");
    setLoading(true);

    const formData = new FormData(event.currentTarget);

    const submittedEmail = formData.get("email") || currentEmail;
    const submittedPassword = formData.get("password") || currentPassword;

    try {
      if (isRegister) {
        await authService.register({
          username: formData.get("username"),
          displayName: formData.get("displayName"),
          email: submittedEmail,
          password: submittedPassword,
        });

        navigate("/verify-email", {
          state: {
            email: submittedEmail,
            fromRegistration: true,
          },
        });
      } else {
        await authService.login({
          email: submittedEmail,
          password: submittedPassword,
        });

        const isAuthenticated = await refreshUser();

        if (!isAuthenticated) {
          throw new Error("Login succeeded, but session verification failed.");
        }

        navigate("/chats", { replace: true });
      }
    } catch (err) {
      setError(err.message || "Request failed. Please try again.");
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="mx-auto w-full max-w-md md:ml-auto">
      <p className="text-xs font-semibold uppercase tracking-[0.2em] text-primary-hover">
        {isRegister ? "Create your account" : "Your space awaits"}
      </p>

      <h2 className="mt-4 text-3xl font-semibold tracking-tight text-ink">
        {isRegister ? "Join NexTalk." : "Welcome back."}
      </h2>

      <form className="mt-8 space-y-5" onSubmit={handleSubmit}>
        {children}

        {error && (
          <p role="alert" className="text-sm text-red-600">
            {error}
          </p>
        )}

        {success && (
          <p role="status" className="text-sm text-[#657D50]">
            {success}
          </p>
        )}

        <div className="space-y-2">
          <label htmlFor="email" className="text-sm font-medium text-ink">
            Email address
          </label>

          <Input
            id="email"
            name="email"
            type="email"
            autoComplete="email"
            placeholder="you@example.com"
            value={currentEmail}
            onChange={(event) => handleEmailChange(event.target.value)}
            required
            maxLength={254}
            className="h-12 rounded-md border-app-border bg-transparent px-4 shadow-none focus-visible:ring-primary"
          />
        </div>

        <div className="space-y-2">
          <label htmlFor="password" className="text-sm font-medium text-ink">
            Password
          </label>

          <Input
            id="password"
            name="password"
            type="password"
            autoComplete={isRegister ? "new-password" : "current-password"}
            placeholder="Enter your password"
            value={currentPassword}
            onChange={(event) => handlePasswordChange(event.target.value)}
            required
            minLength={isRegister ? 8 : 1}
            maxLength={128}
            className="h-12 rounded-md border-app-border bg-transparent px-4 shadow-none focus-visible:ring-primary"
          />
        </div>

        <Button
          type="submit"
          disabled={loading}
          className="h-12 w-full rounded-md bg-primary text-sm font-medium text-[#303329] shadow-none hover:bg-primary-hover"
        >
          {loading
            ? "Please wait..."
            : isRegister
              ? "Create account"
              : "Sign in"}

          {!loading && (
            <span aria-hidden="true" className="ml-2">
              →
            </span>
          )}
        </Button>
      </form>

      <SocialAuthButtons isRegister={isRegister} />

      <p className="mt-6 text-sm text-text-secondary">
        {isRegister ? "Already have an account?" : "New to NexTalk?"}{" "}
        <Link

/**
 * Masks an email address for privacy (e.g., alex.miller@example.com -> al••••r@example.com)
 */
function maskEmail(emailAddress) {
  if (!emailAddress || typeof emailAddress !== "string") return "";
  const parts = emailAddress.trim().split("@");
  if (parts.length !== 2) return emailAddress;

  const [local, domain] = parts;
  if (!local || !domain) return emailAddress;

  let maskedLocal = "";
  if (local.length <= 2) {
    maskedLocal = `${local[0]}*`;
  } else if (local.length <= 4) {
    maskedLocal = `${local[0]}**${local.slice(-1)}`;
  } else {
    maskedLocal = `${local.slice(0, 2)}••••${local.slice(-1)}`;
  }

  return `${maskedLocal}@${domain}`;
}

  const muted = Boolean(chat?.isMuted);

  const [open, setOpen] = useState(false);
  const menuRef = useRef(null);

  useEffect(() => {
    setOpen(false);
  }, [chat?.id]);

  const handleToggleMute = () => {
    onToggleMute?.(chat.id, !muted);
    setOpen(false);
  };
  useEffect(() => {
    const handleOutsideClick = (event) => {
      if (menuRef.current && !menuRef.current.contains(event.target)) {
        setOpen(false);
      }
    };

    const handleEscape = (event) => {
      if (event.key === "Escape") setOpen(false);
    };

    document.addEventListener("mousedown", handleOutsideClick);
    document.addEventListener("keydown", handleEscape);

    return () => {
      document.removeEventListener("mousedown", handleOutsideClick);
      document.removeEventListener("keydown", handleEscape);
    };
  }, []);

  const handleClearChat = () => {
    if (!chat?.messages?.length) return;

    const confirmed = window.confirm(
      `Clear all messages with ${chat.name}? This cannot be undone.`,
    );

    if (confirmed) {
      onClearChat?.(chat.id);
      setOpen(false);
    }
  };

  const handleDeleteConversation = () => {
    const confirmed = window.confirm(
      `Delete your conversation with ${chat.name}? This cannot be undone.`,
    );

    if (confirmed) {
      onDeleteConversation?.(chat.id);
      setOpen(false);
    }
  };

  const menuItems = [
    {
      label: "Contact info",
      Icon: UserRound,
      onClick: () => {
        onContactInfo?.();
        setOpen(false);
      },
    },
    {
      label: "Search messages",
      Icon: Search,
      onClick: () => {
        setOpen(false);
        // Message search will be implemented separately.
      },
      disabled: true,
    },
    {
      label: muted ? "Unmute notifications" : "Mute notifications",
      Icon: muted ? Bell : BellOff,
      onClick: handleToggleMute,
    },
  ];

  return (
    <div className="relative" ref={menuRef}>
      <button
        type="button"
        aria-label="More options"
        aria-haspopup="menu"
        aria-expanded={open}
        onClick={() => setOpen((previous) => !previous)}
        className={`rounded-lg p-2.5 transition-colors ${
          open
            ? "bg-surface-secondary text-primary-hover"
            : "text-text-secondary hover:bg-surface-secondary hover:text-ink"
        }`}
      >
        <MoreHorizontal size={18} />
      </button>

      {open && (
        <div
          role="menu"
          className="absolute right-0 top-full z-50 mt-2 w-56 overflow-hidden rounded-xl border border-app-border bg-surface p-1.5 shadow-lg"
        >
          {menuItems.map(({ label, Icon, onClick, disabled }) => (
            <button
              key={label}
              type="button"
              role="menuitem"
              disabled={disabled}
              onClick={onClick}
              className="flex w-full items-center gap-3 rounded-lg px-3 py-2.5 text-left text-sm text-text-main transition hover:bg-surface-secondary disabled:cursor-not-allowed disabled:opacity-40"
            >
              <Icon size={16} className="text-text-secondary" />
              {label}
              {disabled && (
                <span className="ml-auto text-[10px] text-text-muted">
                  Soon
                </span>
              )}
            </button>
          ))}

          <div className="my-1.5 border-t border-app-border" />

          <button
            type="button"
            role="menuitem"
            disabled={!chat?.messages?.length}
            onClick={handleClearChat}
            className="flex w-full items-center gap-3 rounded-lg px-3 py-2.5 text-left text-sm text-text-secondary transition hover:bg-surface-secondary hover:text-ink disabled:cursor-not-allowed disabled:opacity-40"

import { useState } from "react";
import { useAuth } from "@/context/AuthContext";
import { useNavigate } from "react-router-dom";

import { mockChats } from "@/data/mockChats";
import NavigationRail from "@/components/dashboard/NavigationRail";
import Sidebar from "@/components/dashboard/Sidebar";
import ChatWindow from "@/components/dashboard/ChatWindow";
import DetailsPanel from "@/components/dashboard/DetailsPanel";
import ProfileDialog from "@/components/dashboard/ProfileDialog";

export default function ChatPage() {
  const [chats, setChats] = useState(mockChats);
  const [selectedChatId, setSelectedChatId] = useState("1");
  const [showDetails, setShowDetails] = useState(false);
  const [profileOpen, setProfileOpen] = useState(false);

  const { user, setUser, logout } = useAuth();
  const navigate = useNavigate();

  const selectedChat = chats.find((chat) => chat.id === selectedChatId);

  const handleSelectChat = (chat) => {
    setSelectedChatId(chat.id);

    setChats((previous) =>
      previous.map((item) =>
        item.id === chat.id ? { ...item, unread: 0 } : item,
      ),
    );
  };

  const handleToggleMute = (chatId, muted) => {
    setChats((previous) =>
      previous.map((chat) =>
        chat.id === chatId ? { ...chat, isMuted: muted } : chat,
      ),
    );
  };

  const handleCreateConversation = (selectedUser) => {
    const existingChat = chats.find(
      (chat) =>
        chat.username === selectedUser.username && chat.type !== "group",
    );

    if (existingChat) {
      handleSelectChat(existingChat);
      return;
    }

    const newChat = {
      id: crypto.randomUUID(),
      userId: selectedUser.id,
      name: selectedUser.name,
      username: selectedUser.username,
      avatar: selectedUser.avatar,
      online: selectedUser.online,
      type: "personal",
      unread: 0,
      lastMessage: "",
      time: "",
      messages: [],
    };

    setChats((previous) => [newChat, ...previous]);
    setSelectedChatId(newChat.id);
  };

  const handleClearChat = (chatId) => {
    setChats((previous) =>
      previous.map((chat) =>
        chat.id === chatId
          ? {
              ...chat,
              messages: [],
              lastMessage: "",
              time: "",
              unread: 0,
            }
          : chat,
      ),
    );
  };

  const handleDeleteConversation = (chatId) => {
    const remainingChats = chats.filter((chat) => chat.id !== chatId);

    setChats(remainingChats);

    if (selectedChatId === chatId) {
      setSelectedChatId(remainingChats[0]?.id ?? null);
    }

    setShowDetails(false);
  };

  const handleLogout = async () => {
    try {
      await logout();
    } finally {
      navigate("/login", { replace: true });
    }
  };

  const handleToggleDetails = () => {
    setShowDetails((previous) => !previous);
  };

  return (
    <main className="h-dvh min-h-[600px] bg-app p-4 text-text-main">
      <div
        className={`grid h-full min-h-0 gap-3 ${
          showDetails
            ? "grid-cols-[68px_260px_minmax(0,1fr)_280px]"
            : "grid-cols-[68px_260px_minmax(0,1fr)]"
        }`}
      >
        <NavigationRail
          user={user}
          onProfileClick={() => setProfileOpen(true)}
          onLogout={handleLogout}
        />

        <Sidebar
          chats={chats}
          selectedChat={selectedChat}
          onSelectChat={handleSelectChat}
          onCreateConversation={handleCreateConversation}
          user={user}
          onProfileUpdated={setUser}
          onLogout={handleLogout}
        />

        <ChatWindow
          chat={selectedChat}
          onToggleDetails={() => setShowDetails((prev) => !prev)}
          isDetailsOpen={showDetails}
          onToggleMute={handleToggleMute}
        />

        {showDetails && selectedChat && <DetailsPanel chat={selectedChat} />}

        <ProfileDialog
          open={profileOpen}
          onOpenChange={setProfileOpen}
          user={user}
          onProfileUpdated={setUser}
        />
      </div>
    </main>
  );
}

import { useEffect, useState } from "react";
import { Camera, LoaderCircle, UserRound } from "lucide-react";

import { profileService } from "@/services/profile.service";

import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from "@/components/ui/dialog";

import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";

import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";

export default function ProfileDialog({
  open,
  onOpenChange,
  user,
  onProfileUpdated,
}) {
  const [profile, setProfile] = useState(user);
  const [displayName, setDisplayName] = useState("");
  const [bio, setBio] = useState("");

  const [loading, setLoading] = useState(false);
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState("");
  const [success, setSuccess] = useState("");

  useEffect(() => {
    if (!open) return;

    let cancelled = false;

    const loadProfile = async () => {
      setLoading(true);
      setError("");
      setSuccess("");

      try {
        const data = await profileService.getProfile();

        if (cancelled) return;

        const fetchedProfile = data.profile;

        setProfile(fetchedProfile);
        setDisplayName(fetchedProfile.displayName || "");
        setBio(fetchedProfile.bio || "");
      } catch (err) {
        if (!cancelled) {
          setError(err.message);
        }
      } finally {
        if (!cancelled) {
          setLoading(false);
        }
      }
    };

    loadProfile();

    return () => {
      cancelled = true;
    };
  }, [open]);

  const handleSave = async (event) => {
    event.preventDefault();

    setError("");
    setSuccess("");

    const trimmedName = displayName.trim();
    const trimmedBio = bio.trim();

    if (!trimmedName) {
      setError("Display name cannot be empty.");
      return;
    }

    if (trimmedName.length > 50 || trimmedBio.length > 150) {
      setError("Please check the character limits.");
      return;
    }

    const updates = {};

    if (trimmedName !== profile.displayName) {
      updates.displayName = trimmedName;
    }

    if (trimmedBio !== (profile.bio || "")) {
      updates.bio = trimmedBio;
    }

    if (Object.keys(updates).length === 0) {
      setSuccess("Your profile is already up to date.");
      return;
    }

    setSaving(true);

    try {
      const data = await profileService.updateProfile(updates);

      setProfile(data.profile);
      setDisplayName(data.profile.displayName);
      setBio(data.profile.bio || "");

      onProfileUpdated?.(data.profile);
      setSuccess("Profile updated successfully.");
    } catch (err) {
      setError(err.message);
    } finally {
      setSaving(false);
    }
  };

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-h-[90vh] overflow-y-auto border-app-border bg-surface sm:max-w-md">
        <DialogHeader>
          <DialogTitle className="text-lg font-semibold text-ink">
            Your Profile
          </DialogTitle>

          <DialogDescription className="text-text-secondary">
            Manage your personal information.
          </DialogDescription>
        </DialogHeader>

        {loading ? (
          <div className="flex min-h-60 items-center justify-center">
            <LoaderCircle
              size={24}
              className="animate-spin text-primary-hover"
            />
          </div>
        ) : (
          <form onSubmit={handleSave} className="space-y-5">
            {/* Profile Picture */}
            <div className="flex flex-col items-center gap-2 py-2">
              <div className="relative">
                <Avatar className="size-20">
                  <AvatarImage
                    src={profile?.avatarUrl || undefined}
                    alt={profile?.displayName || "Profile"}
                  />

                  <AvatarFallback className="bg-surface-secondary text-ink">
                    <UserRound size={30} />
                  </AvatarFallback>
                </Avatar>

                <div className="absolute bottom-0 right-0 grid size-7 place-items-center rounded-full border-2 border-surface bg-primary text-ink">
                  <Camera size={13} />
                </div>
              </div>

              <span className="text-xs text-text-secondary">
                Profile picture upload coming next
              </span>
            </div>

            {/* Username */}
            <div className="space-y-1.5">
              <label className="text-xs font-medium text-text-secondary">
                Username
              </label>

              <Input
                value={profile?.username || ""}
                readOnly
                className="h-10 border-app-border bg-surface-secondary text-text-secondary"
              />

              <p className="text-[11px] text-text-muted">
                Your username cannot be changed.
              </p>
            </div>

            {/* Display Name */}
            <div className="space-y-1.5">
              <label
                htmlFor="profile-display-name"
                className="text-xs font-medium text-text-secondary"
              >
                Display name
              </label>

              <Input
                id="profile-display-name"
                value={displayName}
                onChange={(event) => setDisplayName(event.target.value)}
                maxLength={50}
                placeholder="Your display name"
                className="h-10 border-app-border bg-surface"
              />

              <p className="text-right text-[11px] text-text-muted">
                {displayName.length}/50
              </p>
            </div>

            {/* Email */}
            <div className="space-y-1.5">
              <label className="text-xs font-medium text-text-secondary">
                Registered email
              </label>

              <Input
                value={profile?.email || ""}
                readOnly
                className="h-10 border-app-border bg-surface-secondary text-text-secondary"
              />

              <p className="text-[11px] text-text-muted">
                Your registered email address.
              </p>
            </div>

            {/* Bio */}
            <div className="space-y-1.5">
              <label
                htmlFor="profile-bio"
                className="text-xs font-medium text-text-secondary"
              >
                About you
              </label>

              <textarea
                id="profile-bio"
                value={bio}
                onChange={(event) => setBio(event.target.value)}
                maxLength={150}
                rows={3}
                placeholder="Tell people a little about yourself..."
                className="w-full resize-none rounded-lg border border-app-border bg-surface px-3 py-2.5 text-sm text-ink outline-none transition placeholder:text-text-muted focus:border-primary"
              />

              <p className="text-right text-[11px] text-text-muted">
                {bio.length}/150
              </p>
            </div>

            {error && (
              <p role="alert" className="text-xs text-red-600">
                {error}
              </p>
            )}

            {success && (
              <p role="status" className="text-xs text-green-700">
                {success}
              </p>
            )}

            <DialogFooter className="border-app-border bg-surface-secondary/50">
              <Button
                type="button"
                variant="outline"
                onClick={() => onOpenChange(false)}
                disabled={saving}
              >
                Cancel
              </Button>

              <Button
                type="submit"
                disabled={saving || loading}
                className="bg-primary text-ink hover:bg-primary-hover"
              >
                {saving && <LoaderCircle size={15} className="animate-spin" />}
                {saving ? "Saving..." : "Save changes"}
              </Button>
            </DialogFooter>
          </form>
        )}
      </DialogContent>
    </Dialog>
  );
}

import {
  createContext,
  useCallback,
  useContext,
  useEffect,
  useState,
} from "react";
import { authService } from "@/services/auth.service";

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  const refreshUser = useCallback(async () => {
    try {
      const data = await authService.getMe();
      setUser(data.user ?? data.data?.user ?? data.data ?? data);
      return true;
    } catch {
      setUser(null);
      return false;
    }
  }, []);

  useEffect(() => {
    refreshUser().finally(() => setLoading(false));
  }, [refreshUser]);

  const logout = async () => {
    try {
      await authService.logout();
    } finally {
      setUser(null);
    }
  };

  return (
    <AuthContext.Provider
      value={{ user, setUser, loading, refreshUser, logout }}
    >
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const context = useContext(AuthContext);

  if (!context) {
    throw new Error("useAuth must be used inside AuthProvider");
  }

  return context;
}

import { useState } from "react";

import DetailsPanel from "@/components/dashboard/DetailsPanel";

export default function ChatPage() {
  const [chats, setChats] = useState(mockChats);
  const [selectedChatId, setSelectedChatId] = useState("1");
  const [showDetails, setShowDetails] = useState(false);

  const { user, logout } = useAuth();
  const navigate = useNavigate();

  const selectedChat = chats.find(
    (chat) => chat.id === selectedChatId
  );

  const handleSelectChat = (chat) => {
    setSelectedChatId(chat.id);

    setChats((previous) =>
      previous.map((item) =>
        item.id === chat.id ? { ...item, unread: 0 } : item
      )
    );
  };

  const handleLogout = async () => {
    try {
      await logout();
    } finally {
      navigate("/login", { replace: true });
    }
  };

  return (
    <main className="h-dvh min-h-[600px] bg-[#F3F0E9] p-4 text-[#242521]">

        className={`grid h-full min-h-0 gap-3 ${showDetails
            ? "grid-cols-[68px_260px_minmax(0,1fr)_280px]"
            : "grid-cols-[68px_260px_minmax(0,1fr)]"
          }`}
      >
        <NavigationRail />

        <Sidebar
          chats={chats}
          selectedChat={selectedChat}
          onSelectChat={handleSelectChat}
          user={user}
          onLogout={handleLogout}
        />

  );
}

const AUTH_URL = `${import.meta.env.VITE_API_URL}/auth`;

async function request(endpoint, options = {}) {
  const response = await fetch(`${AUTH_URL}${endpoint}`, {
    ...options,
    credentials: "include",
    headers: {
      "Content-Type": "application/json",
      ...options.headers,
    },
  });

  const data = await response.json().catch(() => ({}));

  if (!response.ok) {
    throw new Error(data.message || data.error || "Something went wrong");
  }
  return data;
}

export const authService = {
  register: (userData) =>
    request("/register", {
      method: "POST",
      body: JSON.stringify(userData),
    }),

  login: (credentials) =>
    request("/login", {
      method: "POST",
      body: JSON.stringify(credentials),
    }),

  getMe: () => request("/me"),

  logout: () =>
    request("/logout", {
      method: "GET",
    }),

  verifyEmail: ({ email, code }) =>
    request("/verify-email", {
      method: "POST",
      body: JSON.stringify({ email, code }),
    }),

  resendVerification: ({ email }) =>
    request("/resend-verification", {
      method: "POST",
      body: JSON.stringify({ email }),
    }),

  googleLogin: (code) =>
    request("/google", {
      method: "POST",
      headers: {
        "X-Requested-With": "XmlHttpRequest",
      },
      body: JSON.stringify({ code }),
    }),
};

import { ACCESS_COOKIE_NAME, accessCookieOptions } from "../config/cookie.js";
import { registerUser, loginUser } from "../services/auth.service.js";
import { createAccessToken } from "../utils/token.util.js";
import User from "../models/user.model.js";
import {
  verifyEmailOtp,
  issueEmailOtp,
} from "../services/email-verification.service.js";
import { authenticateWithGoogle } from "../services/google-auth.service.js";

export const handleRegister = async (req, res, next) => {
  try {
    const user = await registerUser(res.locals.validated.body);

    return res.status(201).json({
      success: true,
      message: "Account created. Check your email for a verification code.",
      user,
    });
  } catch (error) {
    next(error);
  }
};

export const handleLogin = async (req, res, next) => {
  try {
    const user = await loginUser(res.locals.validated.body);

    const accessToken = createAccessToken(user.id);
    res.cookie(ACCESS_COOKIE_NAME, accessToken, accessCookieOptions);

    return res.status(200).json({
      success: true,
      message: "Credentials verified successfully",
      user,
    });
  } catch (error) {
    next(error);
  }
};

export const getMe = async (req, res, next) => {
  try {
    const user = await User.findById(req.auth.userId);
    if (!user || user.accountStatus !== "active") {
      return res.status(401).json({
        success: false,
        message: "Authentication required",
      });
    }

    return res.status(200).json({
      success: true,
      user: {
        id: user._id,
        username: user.username,
        displayName: user.displayName,
        email: user.email,
        avatarUrl: user.avatarUrl,
        bio: user.bio,
      },
    });
  } catch (error) {
    next(error);
  }
};

export const handleLogout = (req, res, next) => {
  try {
    res.clearCookie(ACCESS_COOKIE_NAME, accessCookieOptions);
    return res.status(200).json({
      success: true,
      message: "Logout successful",
    });
  } catch (error) {
    next(error);
  }
};

export const handleVerifyEmail = async (req, res, next) => {
  try {
    const { email, code } = res.locals.validated.body;

    await verifyEmailOtp(email, code);

    return res.status(200).json({
      success: true,
      message: "Email verified successfully. You can now log in.",
    });
  } catch (error) {
    next(error);
  }

export const handleResendEmailOtp = async (req, res, next) => {
  try {
    const { email } = res.locals.validated.body;
    const normalizedEmail = email.trim().toLowerCase();

    const user = await User.findOne({ email: normalizedEmail });

    // Avoid revealing whether an email has an account.
    if (user && !user.emailVerified && user.accountStatus === "active") {
      await issueEmailOtp(normalizedEmail);
    }

    return res.status(200).json({
      success: true,
      message:
        "If an eligible unverified account exists, a verification email will be sent.",
    });
  } catch (error) {
    next(error);
  }
};

export const handleGoogleAuth = async (req, res, next) => {
  try {
    // 1. Verify the popup request header
    if (req.get("X-Requested-With") !== "XmlHttpRequest") {
      const error = new Error("Invalid authentication request");
      error.statusCode = 400;
      throw error;
    }

    // 2. Authenticate the user through Google
    const user = await authenticateWithGoogle(req.body.code);

    // 3. Generate NexTalk's own access token
    const accessToken = createAccessToken(user._id);

    // 4. Store the token in a an HttpOnly cookie
    res.cookie(ACCESS_COOKIE_NAME, accessToken, accessCookieOptions);

    // 5. Send user information to the frontend.
    return res.status(200).json({
      success: true,
      message: "Google authentication successful",
      user: {
        id: user._id,
        username: user.username,
        displayName: user.displayName,
        email: user.email,
        avatarUrl: user.avatarUrl,
        bio: user.bio,
      },
    });
  } catch (error) {
    next(error);
  }
};

export const uploadProfileAvatar = async (req, res, next) => {
  let uploadedAvatar;
  try {
    const user = User.findOne({
      _id: req.auth.userId,
      accountStatus: "active",
    });

    if (!user) {
      return res.status(401).json({
        success: false,
        message: "Authentication failed",
      });
    }

    // preserving old avatar id
    const oldPublicId = user.avatarPublicId;

    // uploading new avatar to cloudinary
    uploadedAvatar = await uploadAvatarToCloudinary(req.file.buffer);

    // updated the user's profile
    user.avatarUrl = uploadedAvatar.secureUrl;
    user.avatarPublicId = uploadedAvatar.publicId;

    await user.save();

    if (oldPublicId) {
      try {
        await deleteAvatarFromCloudinary(oldPublicId);
      } catch (deleteError) {
        // new avatar is already saved so delete the old one to save storage
        console.error("failed to delete previous avatar: deleteError.message");
      }
    }

    return res.status(200).json({
      success: true,
      message: "Profile picture updated successfully",
      profile: {
        id: user._id,
        username: user.username,
        displayName: user.displayName,
        email: user.email,
        avatarUrl: user.avatarUrl,
        bio: user.bio,
      },
    });
  } catch (error) {
    if (uploadedAvatar?.publicId) {
      try {
        await deleteAvatarFromCloudinary(uploadedAvatar.publicId);
      } catch (cleanupError) {
        console.error(
          "Failed to clean up uploaded avatar:",
          cleanupError.message,
        );
      }
    }

    next(error);
  }
};

import JWT from "jsonwebtoken";
import { env } from "../config/env.js";
import { ACCESS_COOKIE_NAME } from "../config/cookie.js";

export const requireAuth = (req, res, next) => {
  const token = req.cookies?.[ACCESS_COOKIE_NAME];

  if (!token) {
    return res.status(401).json({
      success: false,
      message: "Authentication required",
    });
  }

  try {
    const payload = JWT.verify(token, env.JWT_ACCESS_SECRET, {
      algorithms: ["HS256"],
      issuer: "nextalk-api",
      audience: "nextalk-client",
    });

    const isValidObjectId = /^[a-f\d]{24}$/i.test(payload?.sub);

    if (
      typeof payload === "string" ||
      typeof payload.sub !== "string" ||
      !isValidObjectId
    ) {
      return res.status(401).json({
        success: false,
        message: "Invalid or expired authentication token",
      });
    }

    req.auth = {
      userId: payload.sub,
    };

    return next();
  } catch (error) {
    return res.status(401).json({
      success: false,
      message: "Invalid or expired authentication token",
    });
  }
};

import multer from "multer";
import { fileTypeFromBuffer } from "file-type";

const ALLOWED_IMAGE_TYPES = ["image/jpeg", "image/png", "image/webp"];

const upload = multer({
  storage: multer.memoryStorage(),

  limits: {
    fileSize: 5 * 1024 * 1024, // 5 MB
    files: 1,
  },

  fileFilter: (req, file, callback) => {
    if (!ALLOWED_IMAGE_TYPES.includes(file.mimetype)) {
      return callback(new Error("Only JPEG, PNG and WebP images are allowed."));
    }

    callback(null, true);
  },
});

// Verify actual file content, not just its MIME type.
export const validateAvatarContent = async (req, res, next) => {
  try {
    if (!req.file) {
      return res.status(400).json({
        success: false,
        message: "Profile picture is required.",
      });
    }

    const detectedType = await fileTypeFromBuffer(req.file.buffer);

    if (!detectedType || !ALLOWED_IMAGE_TYPES.includes(detectedType.mime)) {
      return res.status(400).json({
        success: false,
        message: "Invalid image file.",
      });
    }

    req.file.detectedMimeType = detectedType.mime;

    next();
  } catch (error) {
    next(error);
  }
};

export const uploadAvatar = upload.single("avatar");

export const validate = (schema, property = "body") => {
  return async (req, res, next) => {
    try {
      const result = await schema.safeParseAsync(req[property]);

      if (!result.success) {
        return res.status(400).json({
          success: false,
          message: "Validation failed",
          errors: result.error.issues.map((issue) => ({
            field: issue.path.join("."),
            message: issue.message,
          })),
        });
      }

      res.locals.validated ??= {};
      res.locals.validated[property] = result.data;
      next();
    } catch (error) {
      next(error);
    }
  };
};

import User from "../models/user.model.js";
import { hashPassword, verifyPassword } from "../utils/password.util.js";
import { issueEmailOtp } from "./email-verification.service.js";

export const registerUser = async ({
    username,
    displayName,
    email,
    password,
}) => {
    const existingUser = await User.findOne({
        $or: [{ email }, { username }],
    });

    if (existingUser) {
        const error = new Error("Username or email is already taken");
        error.statusCode = 409;
        throw error;
    }

    const passwordHash = await hashPassword(password);

    try {
        const user = await User.create({
            username,
            displayName,
            email,
            passwordHash,
        });

        await issueEmailOtp(user.email);

        return {
            id: user._id,
            username: user.username,
            displayName: user.displayName,
            email: user.email,
            avatarUrl: user.avatarUrl,
            bio: user.bio,
            createdAt: user.createdAt,
        };
    } catch (error) {
        if (error.code === 11000) {
            const duplicateError = new Error(
                "Username or email is already taken"
            );
            duplicateError.statusCode = 409;
            throw duplicateError;
        }

        throw error;
    }
};

            throw error;

            username: user.username,
            displayName: user.displayName,
            email: user.email,
            avatarUrl: user.avatarUrl,
            bio: user.bio,
        };

import { createHmac, randomInt, timingSafeEqual } from "crypto";
import { env } from "../config/env.js";
import User from "../models/user.model.js";
import EmailVerification from "../models/email-verfication.js";
import { sendVerificationEmail } from "./email.service.js";

const OTP_TTL_MS = 5 * 60 * 1000;
const RESEND_COOLDOWN_MS = 60 * 1000;
const MAX_ATTEMPTS = 5;

function createOtp() {
    return randomInt(0, 1_000_000).toString().padStart(6, "0");
}

function hashOtp(email, code) {
    return createHmac("sha256", env.OTP_HASH_SECRET)
        .update(`${email}:${code}`)
        .digest("hex");
}

function safeEqualHex(a, b) {
    const left = Buffer.from(a, "hex");
    const right = Buffer.from(b, "hex");

    return left.length === right.length && timingSafeEqual(left, right);
}

function createError(message, statusCode) {
    const error = new Error(message);
    error.statusCode = statusCode;
    return error;
}

export async function issueEmailOtp(email) {
    const normalizedEmail = email.trim().toLowerCase();
    const now = new Date();

    const existing = await EmailVerification.findOne({
        email: normalizedEmail,
    });

    if (existing && now - existing.lastSentAt < RESEND_COOLDOWN_MS) {
        throw createError("Please wait before requesting another code.", 429);
    }

    const code = createOtp();
    const record = await EmailVerification.findOneAndUpdate(
        { email: normalizedEmail },
        {
            $set: {
                codeHash: hashOtp(normalizedEmail, code),
                expiresAt: new Date(now.getTime() + OTP_TTL_MS),
                attempts: 0,
                lastSentAt: now,
            },
        },
        {
            upsert: true,
            new: true,
            runValidators: true,
            setDefaultsOnInsert: true,
        },
    );

    try {
        await sendVerificationEmail({
            to: normalizedEmail,
            code,
        });
    } catch {
        await EmailVerification.deleteOne({ _id: record._id });
        throw createError(
            "We couldn't send the verification email. Please try again shortly.",
            503,
        );
    }

    return { sent: true };
}

export async function verifyEmailOtp(email, code) {
    const normalizedEmail = email.trim().toLowerCase();
    const record = await EmailVerification.findOne({
        email: normalizedEmail,
    }).select("+codeHash");

    if (!record) {
        throw createError("Invalid or expired verification code.", 400);
    }

    if (record.expiresAt <= new Date()) {
        await EmailVerification.deleteOne({ _id: record._id });
        throw createError("Invalid or expired verification code.", 400);
    }

    if (record.attempts >= MAX_ATTEMPTS) {
        await EmailVerification.deleteOne({ _id: record._id });
        throw createError("Too many attempts. Request a new code.", 429);
    }

    const candidateHash = hashOtp(normalizedEmail, code);

    if (!safeEqualHex(candidateHash, record.codeHash)) {
        const updated = await EmailVerification.findOneAndUpdate(
            { _id: record._id, attempts: { $lt: MAX_ATTEMPTS } },
            { $inc: { attempts: 1 } },
            { new: true },
        );

        if (!updated || updated.attempts >= MAX_ATTEMPTS) {
            throw createError("Too many attempts. Request a new code.", 429);
        }

        throw createError("Invalid or expired verification code.", 400);
    }

    // Consume the OTP atomically so it cannot be reused.
    const consumed = await EmailVerification.findOneAndDelete({
        _id: record._id,
        codeHash: record.codeHash,
        attempts: { $lt: MAX_ATTEMPTS },
        expiresAt: { $gt: new Date() },
    });

    if (!consumed) {
        throw createError("Invalid or expired verification code.", 400);
    }

    const result = await User.updateOne(
        { email: normalizedEmail, emailVerified: false },
        { $set: { emailVerified: true } },
    );

    if (result.matchedCount === 0) {
        const user = await User.findOne({ email: normalizedEmail });

        if (!user) {
            throw createError("Account not found.", 404);
        }

        if (!user.emailVerified) {
            throw createError("Unable to verify this email. Please try again.", 500);
        }
    }

    return { verified: true };
}

function escapeHtml(value) {
    return String(value).replace(/[&<>"']/g, (character) => {
        const entities = {
            "&": "&amp;",

            "'": "&#39;",

    });

import { OAuth2Client } from "google-auth-library";
import { randomInt } from "node:crypto";

import { env } from "../config/env.js";
import User from "../models/user.model.js";

const googleClient = new OAuth2Client(
  env.GOOGLE_CLIENT_ID,
  env.GOOGLE_CLIENT_SECRET,
  env.FRONTEND_URL,
);

const generateUsername = async (email) => {
  const baseUsername = email
    .split("@")[0]
    .toLowerCase()
    .replace(/[^a-z0-9_]/g, "_")
    .replace(/_+/g, "_")
    .replace(/^_|_$/g, "")
    .slice(0, 20);

  const safeBase = baseUsername.length >= 3 ? baseUsername : `user_${baseUsername}`;

  let username;

  do {
    username = `${safeBase}_${randomInt(100000, 999999)}`;
  } while (await User.exists({ username }));

  return username;
};

export const authenticateWithGoogle = async (code) => {
  // 1. Exchange authorization code for Google tokens.
  const { tokens } = await googleClient.getToken({
    code,
    redirect_uri: env.FRONTEND_URL,
  });

  if (!tokens.id_token) {
    throw new Error("Google did not return an ID token");
  }

  // 2. Verify Google's ID token.
  const ticket = await googleClient.verifyIdToken({
    idToken: tokens.id_token,
    audience: env.GOOGLE_CLIENT_ID,
  });

  const payload = ticket.getPayload();

  if (!payload?.sub || !payload.email || payload.email_verified !== true) {
    const error = new Error("Google account could not be verified");
    error.statusCode = 401;
    throw error;
  }

  const googleId = payload.sub;
  const email = payload.email.toLowerCase();

  // 3. Check whether this Google account already exists.
  let user = await User.findOne({ googleId });

  if (user) {
    if (user.accountStatus !== "active") {
      const error = new Error("This account is unavailable");
      error.statusCode = 403;
      throw error;
    }

    return user;
  }

  // 4. Do not automatically link accounts by email.
  const existingEmailUser = await User.findOne({ email });

  if (existingEmailUser) {
    const error = new Error(
      "An account with this email already exists. Please sign in using your existing method.",
    );
    error.statusCode = 409;
    throw error;
  }

  // 5. Create a new Google-only user.
  const username = await generateUsername(email);

  user = await User.create({
    username,
    displayName: payload.name || email.split("@")[0],
    email,
    googleId,
    avatarUrl: payload.picture || null,
    emailVerified: true,
  });

  return user;
};
